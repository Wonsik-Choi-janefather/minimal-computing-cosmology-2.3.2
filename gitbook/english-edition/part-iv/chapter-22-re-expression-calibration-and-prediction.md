# Chapter 22 Re-expression, Calibration, and Prediction

Transferring Standard-Model parameters into WRRA notation is re-expression. Re-recording the same numbers and relations in the ownership language of LAW, SOURCE, RELATION, and BOUNDARY may yield structural insight, but does not create a new numerical prediction.

Calibration uses restricted observational data to determine the renderer's free parameters or boundary conditions. A calibrated model's good reproduction of those data is a consistency check, not an independent prediction. The numbers of free parameters and calibration data must be disclosed together for goodness of fit to have meaning.

Independent prediction begins when an observable not used for calibration is calculated by a procedure specified in advance. If parameters or the filter structure are altered after the prediction, that value becomes calibration data for the next version and a new held-out target must be designated.

$$
Prediction = O_T(θ̂(C)) with T ∩ C = ∅
$$

_Equation (4.3)_

The three layers are a research sequence, not a ranking. Re-expression creates a correspondence table between theoretical languages; calibration narrows the numerically possible region; independent prediction tests whether that region actually agrees with nature. Only when the first two layers are exact can a failure at the third be interpreted.

Predictive power is not measured simply by the number of correct values. The number of independent inputs used, allowed error, selection bias, and number of post hoc revisions must all be considered. An appropriate WRRA validation score records held-out residuals and complexity cost simultaneously.

$$
χ²_hold = Σ\_(i∈T) \[(O_i^model−O_i^obs)/σ_i\]²
$$

_Equation (4.4)_

Throughout this book, therefore, “derived” is used only when an equation and input ledger are supplied together. Moving an observed value into new notation is re-expression; fitting a value is calibration; only matching sealed data is called prediction.
