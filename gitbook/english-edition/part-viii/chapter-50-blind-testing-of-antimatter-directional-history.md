# Chapter 50 Blind Testing of Antimatter Directional History

**Conclusion of this chapter:** The existence of positrons and pair plasma is already a result of standard QED and plasma physics. WRRA is tested on whether a directional-history residual remains after every local state is calculated by standard theory.

For the gravitational time t\_g = GM/c³ of a neutral stellar-mass black-hole merger, ℏ/t\_g is far below the e⁺e⁻ rest energy. Observable pair discharge requires magnetized plasma, reconnection, a high-energy photon field, and the γγ threshold. Production satisfies N(e⁺) = N(e⁻); net positron escape is a separate asymmetry problem A\_esc produced by magnetic polarity, open fields, and escape rates.

Directional history h\_X is a normalized difference obtained by averaging the past return and outgoing energy-momentum fluxes through a causal kernel K\_X for a specified observer and directed surface. The 1/2 in ζ\_X = (1+h\_X)/2 is an operational boundary at which the two fluxes balance, not the critical line of Riemann ζ.

hX(τ)=∫KX(s)\[Φret(τ−s)−Φout(τ−s)]ds / {∫KX(s)\[|Φret|+|Φout|]ds+ε} (8.10)

The black-hole-merger test preregisters branches by gamma-ray optical depth. The transparent branch tests a hard-gamma rise near the GW peak followed by screening decay and jet recovery; the opaque branch tests gamma suppression, pair loading, Comptonized X-rays, and delayed radio or polarization changes. It uses the same environmental priors and selection function as the standard GRMHD+QED model and compares them by a holdout predictive score.

For the strong-field accelerator test, the assumption of raw-yield equality between direct and return paths is abandoned. The full electromagnetic field, waveform, phase, polarization, focus, particle distribution, detector response, and background for each shot are entered into a QED digital twin to calculate μ\_QED,k. Because normalized residual R\_k can have a sign, A\_H = (R\_R−R\_D)/(R\_R+R\_D) is used only under the preregistered condition |R\_R+R\_D| ≥ δ\_den; otherwise, the primary statistic ΔR = R\_R−R\_D and full likelihood must be reported.

AH=(RR−RD)/(RR+RD) if |RR+RD|≥δden; ΔR=RR−RD (8.11)

A positive WRRA candidate must appear only in the strong-field regime χ\_γ = 1–3, reverse sign when circulation direction is reversed, increase monotonically with loop count, and vanish on a sham path. The engineering target is |A\_H| = 2%, with residual systematics no greater than 0.2%, but the actual primary test must include preregistered likelihood, nuisance parameters, shot correlations, multiple-testing correction, and δ\_den. Both global 5σ and independent beamline replication are required; if the null's 95% interval lies within ±2%, a directional-history hypothesis of that magnitude or larger is rejected.

Antiprotons form a separate hadronic module and are considered only after the L1 pair test is reproduced at two facilities. If both astrophysical and accelerator tests are null, this paper's WRRA antimatter/pair-plasma subhypothesis is rejected. The memory kernel, effect size, and common microscopic operator remain OPEN.
