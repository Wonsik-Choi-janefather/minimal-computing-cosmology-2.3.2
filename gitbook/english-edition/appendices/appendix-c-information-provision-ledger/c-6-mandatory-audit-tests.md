# C-6 Mandatory Audit Tests

**No hidden preloading A value claimed as a prediction must not already be present in LAW, SOURCE, or a calibration field.**

**Reconstruction test** After deleting a DERIVED field, it must be recalculable within the declared error.

**Read-order test** Order should be stored as separate information only when noncommutative dependence exists.

**Address–space distinction Do not identify LAW’s abstract state or relational address with a visible three-dimensional coordinate without justification.**

**Global-definition test** The total size and mass of the universe require definitions of topology, domain, and gravity.

**Shared-record consistency** Overlapping observational queries must give the same answer for protected common observables.

**Preservation of open events** Future outcomes must not be hidden under another name in the boot package.

**Calibration–prediction separation** Separate observations used to fit parameters from observations reserved for predictive testing.
