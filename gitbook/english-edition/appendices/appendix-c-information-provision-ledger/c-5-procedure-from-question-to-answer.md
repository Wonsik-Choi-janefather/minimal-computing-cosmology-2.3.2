# C-5 Procedure from Question to Answer

1. Specify what is to be known and at what precision. Distinguish “the total size of the universe” from “the radius of the observable universe.”
2. Identify the first owner among the LAW HEADER, dormant state, SOURCE, global sector, renderer, phenotypic grammar, current state, and event apparatus.
3. Remove redundant fields reproducible from the previous stage and read only the minimum payload actually needed.
4. Declare the scale, boundary, renormalization prescription, and error tolerance, then run the execution rule.
5. Determine whether the answer is a state value, probability distribution, calibrated estimate, or newly realized event.
6. Attach a status grade and uncertainty to the stable record, and separate inputs from independent predictions.
