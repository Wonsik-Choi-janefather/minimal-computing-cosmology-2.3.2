# 제5부 끈이론 미시재료의 선택적 보강

**제0장. 최소계산우주론 2.0과 끈이론의 비교**

이 문서는 두 이론을 같은 지위에서 섞는 통합문서가 아니다. 최소계산우주론 2.0은 우주의 SOURCE에서 하나의 Reality와 Record까지 이어지는 상위 실행구조를 소유한다. 끈이론은 그 실행구조 안에서 아직 약한 미시적 양자중력, anomaly 폐쇄, 카이럴 물질의 미시기원, 블랙홀 미시상태와 같은 부분을 보강하는 재료로 사용한다. 이 관계를 한 문장으로 정리하면 ’MCC/WRRA가 뼈대이고 string theory가 수리 재료’이다.

비교의 결론은 상호대체가 아니라 역할분담이다. 2024년 Annual Review의 정리처럼 끈이론은 quantum gravity와 gauge/gravity의 공동 미시기원 및 4차원 Standard Model형 compactification에 강한 자원을 제공하지만, 어떤 compactification이 우리 우주인가와 초기우주 역사 전체를 하나로 선택하는 문제는 여전히 연구 프로그램으로 남아 있다 \[S1]. MCC는 바로 이 선택·실행·표현·기록의 상위 장부를 유지한다.

**Statement**

결합의 비대칭성 String theory가 MCC의 SOURCE, 최소계산, 공통운반자, 표현형, Actual–Reality 구분을 바꾸면 이 결합은 실패다. 반대로 MCC가 string theory의 검증된 미시수학을 ’우리 용어로 다시 이름만 붙이는 것’도 실패다. 기존 string 결과는 BASELINE/IMPORTED MICROPHYSICS로 표시하고, MCC가 새로 하는 일은 소유권·선택·실행순서·최소성의 연결로 제한한다.
