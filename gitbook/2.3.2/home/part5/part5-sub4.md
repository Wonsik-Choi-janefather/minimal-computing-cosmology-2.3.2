# 제4부. 정보·선택·경계

## 13장. 블랙홀 WRRA 경계의 의미 + string microstates

여기서는 두 이론의 역할분담이 가장 깨끗하다. WRRA는 왜 horizon/boundary가 내부 Reality를 위한 최소 충분기록이 될 수 있는지, 정보가 어떤 owner와 record에 남는지를 설명한다. string theory는 특정 extremal/BPS black hole에서 실제 microscopic state degeneracy를 세어 Bekenstein–Hawking entropy를 재현한 대표적 성과를 갖는다 \[S3].

**Equation (13.1)**

S\_BH = k\_B ln Ω\_string = k\_B A/(4ℓ\_P²) (specific controlled sectors)

따라서 MCC가 string microstate counting을 자기 도출로 주장하지 않는다. 대신 compatibility fiber C(ρ)와 boundary record의 미시 상태수를 Ω\_string과 연결한다.

**Equation (13.2)**

C(ρ\_∂) = {Ω\_Actual : R\_∂(Ω\_Actual)=ρ\_∂}

**Equation (13.3)**

|C(ρ\_∂)| ↔ Ω\_string (candidate microscopic identification)

이 identification이 성립하면 WRRA의 ’경계가 왜 충분한가’와 string theory의 ’경계에 대응하는 미시상태가 몇 개인가’가 서로 보완된다. generic astrophysical black hole 전체에 대한 완전한 microstate count가 끝났다는 뜻은 아니다.

## 14장. duality를 Reality equivalence로 배치하기

string theory의 T/S duality는 서로 다른 microscopic description이 같은 physics를 줄 수 있다는 강력한 사례다. MCC는 이를 자신의 Actual–Reality 분리 안에 넣는다.

**Equation (14.1)**

Φ\_A \~\_R Φ\_B ⇔ R\_vis∘Φ\_A = R\_vis∘Φ\_B on A\_protected

string duality가 식 (14.1)의 구체적 예가 될 수 있다. 그러나 MCC는 모든 Reality-equivalence가 string duality라고 주장하지 않는다. 오히려 string duality를 ’동일 Reality의 다른 Actual description’이라는 상위 언어로 배치한다.

동치류 안에서도 계산비용이 다를 수 있다. MCC는 같은 Reality를 주는 description 가운데 비용이 낮은 representative를 canonical implementation 후보로 둘 수 있다.

**Equation (14.2)**

C̄(\[Φ]) = inf\_(Ψ∈\[Φ]) C\_hybrid(Ψ)

두 description의 비용이 정확히 같으면 둘 다 최소해로 남는다. 선택자를 가정할 필요는 없다.

## 15장. string landscape를 최소계산으로 거르기

끈이론의 가장 큰 구조적 난점 중 하나는 많은 compactification/vacuum이 가능하다는 점이다. flux compactification과 moduli stabilization은 방대한 연구분야를 형성했고, 현실적 4D model을 얻는 과정에는 geometry, topology, bundle/brane, flux와 vacuum choice가 개입한다 \[S1,S4]. MCC는 이곳에서 가장 중요한 새 역할을 맡는다.

**Equation (15.1)**

𝒱\_string = {v\_i = (K\_6, bundle/brane, flux, moduli, …)}

먼저 관측계약을 만족하지 않는 vacuum을 제거한다.

**Equation (15.2)**

𝒱\_obs = {v ∈ 𝒱\_string : v ⊨ Ω\_observed}

그 다음 동일한 관측범위를 만드는 후보에 최소계산 장부를 적용한다.

**Equation (15.3)**

𝒱\_MCC = ParetoMin{ C\_hybrid(v) | v ∈ 𝒱\_obs }

비용항에는 compact dimension 자체보다 moduli 수, 독립 flux 선택, 추가 light field, 별도 carrier, 사후 tuning과 update cost가 중요하게 들어간다. 이 원리는 landscape를 ’무한히 많은 가능성도 다 설명이다’라고 받아들이지 않고, 실제 구현의 설명경제를 요구한다.

**Statement**

MCC가 끈이론에 제공하는 것 String theory는 가능한 미시 세계들을 만든다. MCC는 그중 우리 Reality와 호환되는 후보를 최소계산·공통운반자·표현형의 세 기준으로 거르는 selection layer를 제공한다. 이 selection이 실제 vacuum ranking을 낼 때 결합이론의 독립 성과가 된다.
