## 18장. 남은 OPEN과 실패조건

### 18.1 실제로 남은 OPEN

**•** MCC cost ledger를 실제 string compactification 후보군에 적용해 하나 이상의 vacuum을 비자명하게 탈락시키는 계산.

**•** 공통운반자 식 (6.3)을 구체 E8×E8 compactification의 15개 한세대 chiral zero mode에 대해 명시적으로 구성.

**•** index=3뿐 아니라 정확한 Standard Model representation, hypercharge normalization과 anomaly-free low-energy spectrum을 한 instance에서 확인.

**•** string-derived gauge kinetic function/modulus spectrum에서 Qr를 계산하여 opening→hot Big Bang의 전이온도 T\_RD를 독립적으로 산출.

**•** 최소비용 baryogenesis source를 고르고 ηB를 관측값을 보정에 쓰지 않은 상태에서 계산.

**•** phenotype layer에서 Yukawa/RG/dressing까지 포함한 적어도 한 개의 질량비 또는 coupling relation을 독립 출력.

**•** generic black-hole sector에서 WRRA compatibility fiber와 string microstate space의 관계를 특정 controlled example 이상으로 확장.

### 18.2 결합이 실패하는 조건

**•** 끈이론의 10D/compactification을 받아들이는 순간 최소계산, 공통운반자 또는 표현형 중 하나를 삭제하거나 주변화해야 하는 경우.
