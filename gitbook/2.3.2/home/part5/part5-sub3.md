# 제3부. 우주사 보강

## 9장. SOURCE와 Big Bang의 소유권은 MCC에 남는다

string cosmology에는 inflation, reheating, moduli domination, kination, string/brane gas, pre-Big-Bang, ekpyrotic/cyclic 등 다양한 초기우주 시나리오가 존재한다 \[S2]. 본 결합에서는 그 다양성을 MCC의 SOURCE 위에 덮어쓰지 않는다. 우주의 시작은 기존 2.0의 dormant state와 constraint-preserving opening이 소유한다.

**Equation (9.1)**

ρ\_dorm ─B\_η→ opening → execution

**Equation (9.2)**

B\_η(a,χ) = ηχ − √6 M̄\_P|η| ln(a/a\*) + constant

string theory가 제공할 수 있는 것은 χ의 microscopic identity 또는 opening 이후의 interaction owner이다. 예를 들어 χ가 compactification modulus, dilaton-like mode 또는 다른 string-derived scalar의 4D effective coordinate로 realization될 수 있다. 하지만 η를 여러 string vacuum label로 바꾸거나, SOURCE에 moduli 값을 무제한으로 추가하면 최소 SOURCE가 깨진다.

**Statement**

SOURCE veto compactification에 필요한 modulus/flux/bundle data는 LAW/instance specification으로 공개해야 하며, 미래 사건이나 hot Big Bang의 방사량·바리온 비대칭을 숨기는 추가 primordial register로 사용해서는 안 된다.

## 10장. radiation transfer owner Qr의 string 재료

MCC 2.0 최종본에서 opening→hot Big Bang 연결의 가장 중요한 OPEN은 microscopic energy-transfer owner Qr이다. string compactification은 scalar moduli와 gauge kinetic function을 자연스럽게 제공하므로 이 빈칸을 직접 보강할 수 있다.

**Equation (10.1)**

ℒ\_gauge ⊃ −(1/4) Re f\_a(Φ) F\_a,μνF\_a^μν − (1/4) Im f\_a(Φ) F\_a,μν F̃\_a^μν

opening field χ 또는 그것과 섞인 modulus Φ가 시간에 따라 진화하거나 붕괴하면 gauge sector로 에너지가 이동할 수 있다. coarse-grained cosmology에서는 다음처럼 쓸 수 있다.

**Equation (10.2)**

ρ̇\_χ + 6Hρ\_χ = −Q\_r, ρ̇\_r + 4Hρ\_r = +Q\_r

**Equation (10.3)**

Q\_r ≃ Σ\_a Γ\_(Φ→a) ρ\_Φ + Q\_nonpert + …

식 (10.3)은 Qr가 더 이상 정체불명의 phenomenological 함수일 필요가 없음을 보여준다. 구체 compactification과 gauge kinetic function이 정해지면 decay width와 production rate를 계산할 owner가 생긴다. 수치 자체는 compactification이 확정되지 않았으므로 OPEN으로 남긴다.

이 보강은 No Extra Radiation Register와 잘 맞는다. radiation seed를 SOURCE에 넣는 대신 LAW에 포함된 string-derived interaction이 실행 중 radiation을 만든다.

**Equation (10.4)**

ρ\_r(t) = a(t)^(−4) ∫\_(t\*)^t a(t’)^4 Q\_r(t’) dt’

따라서 string microphysics는 Big Bang의 주인이 아니라, MCC opening이 hot Big Bang으로 넘어갈 때 필요한 ’에너지 전달 재료’의 주인이 된다.

## 11장. 물질 반물질 비대칭 source의 string 재료

MCC의 물질 우세 Reality 명제는 두 층을 분리한다. LAW는 matter/antimatter channel을 모두 허용할 수 있지만 actual occupancy는 비대칭일 수 있다. 남은 OPEN은 ΔB 또는 source S\_B−S\_Bbar의 microscopic owner이다.

**Equation (11.1)**

d\[a³Δ\_B]/dt = a³(S\_B − S\_B̄)

string compactification은 CP phase, heavy singlet states, moduli/axion couplings, supersymmetric flat directions 등 baryogenesis/leptogenesis에 필요한 다양한 microscopic ingredients를 제공할 수 있다 \[S2]. 그러나 string theory 자체가 하나의 유일한 baryogenesis mechanism을 강제하지는 않는다. 따라서 MCC는 후보 mechanism을 cost ledger에 넣어 선택한다.

**Ledger — 후보 재료 · 장점 · 비용/위험 · 판정**

* **후보 재료:** Heavy singlet / leptogenesis
  * **장점:** compactification에서 singlet과 Majorana term이 존재할 경우 사용
  * **비용/위험:** 추가 heavy-state owner·CP phase·decay 계산
  * **판정:** 후보
* **후보 재료:** Affleck–Dine형 flat direction
  * **장점:** 4D SUSY effective theory의 flat direction 사용
  * **비용/위험:** scalar direction·lifting operator·late decay
  * **판정:** 후보
* **후보 재료:** Modulus/axion-driven source
  * **장점:** string-derived scalar의 CP-odd coupling과 비평형 decay
  * **비용/위험:** coupling·stabilization 의존
  * **판정:** 후보

최소계산 원칙은 ’유명한 mechanism’을 고르는 것이 아니라, 이미 필요한 field content를 재사용하면서 별도 초기값을 추가하지 않고 관측 ηB를 만드는 가장 작은 viable source를 선택한다.

**Equation (11.2)**

η\_B,f = \[a\*³Δ\_B,\* + ∫a³(S\_B−S\_B̄)dt] / S\_com

No Extra Asymmetry Register는 그대로 유지한다. 정확한 CP symmetry와 baryon-number conservation만 있는 LAW에서는 임의 비대칭이 나오면 안 된다.

**Equation (11.3)**

F\_B(η, LAW\_CP-symmetric) = 0

**Statement**

물질 우세는 phenotype/occupancy 결과 string theory는 asymmetry source의 microscopic 재료를 제공할 수 있지만, ’물질 우세 Reality’라는 구분 자체와 matter/antimatter의 lawful-vs-occupied distinction은 MCC가 계속 소유한다.

## 12장. 암흑부문의 string 재료

MCC 2.0에서 dark matter의 최소 조건은 gauge current에는 거의 보이지 않지만 실제 stress-energy를 가져 중력장부에는 남는 것이다. string compactification은 axion-like fields, moduli, hidden gauge sectors 등 이 조건을 만족할 후보를 풍부하게 제공한다.

**Equation (12.1)**

J\_SM\[X] ≃ 0, T\_μν\[X] ≠ 0, τ\_X ≫ H\_0^(−1)

특히 antisymmetric B-field와 compact cycles에서 내려오는 axion-like mode는 ‘hidden internal degree가 4D phenotype으로 나타나는’ 좋은 사례다. 다만 후보가 많다는 것은 선택문제를 다시 만든다. 따라서 dark-sector candidate도 string landscape에서 자동 채택하지 않고 MCC Pareto filter를 통과해야 한다.

암흑에너지 역시 string landscape의 cosmological constant, quintessence/moduli 후보를 그대로 정답으로 가져오지 않는다. 현재 2.0에서 Λ는 BASELINE/observed low-energy parameter로 유지하고, string material이 비용과 관측을 개선할 때만 상류 realization 후보로 채택한다.
