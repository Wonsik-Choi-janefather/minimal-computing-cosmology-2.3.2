# 용어 정의

**Ledger — 용어 · 정의**

* **용어:** WRRA
  * **정의:** 상태 관계 법칙 경계 갱신 표현형과 기록을 조직하는 상위 실행 문법
* **용어:** 최소계산
  * **정의:** 변화하는 환경에서 치명적 실패를 피할 만큼의 계산과 여분을 유지하는 원리
* **용어:** Actual
  * **정의:** 공통운반자 경계 관계 현재 상태와 뒤틀림이 속하는 존재 층
* **용어:** Renderer
  * **정의:** Actual 상태를 Reality의 입자 장 질량 거리 시간으로 귀속하는 대응
* **용어:** Reality
  * **정의:** 관측자가 표준 물리학 방정식으로 계산하는 유효 현실 층
* **용어:** Record
  * **정의:** 관측값 출처 오차와 적용 범위를 보존한 기록
* **용어:** Ledger
  * **정의:** 모듈 버전 소유권 갱신과 실패 이력을 관리하는 장부
* **용어:** 공통운반자
  * **정의:** 추가 입자가 아니라 Actual에서 변화와 전달을 가능하게 하는 공통 기반
* **용어:** 표현형
  * **정의:** Renderer를 거쳐 관측 가능한 성질로 나타난 결과
* **용어:** 뒤틀림
  * **정의:** 닫힌 연결을 따라 상태를 운반한 뒤 남는 전역 또는 국소 관계의 잔여
* 용어: 보통물질 질량 표현형
  * 정의: 닫힌 내부 모드의 이산 질량 전구체가 표준모형·QCD dressing과 공동귀속을 거쳐 Reality의 관성·중력 질량으로 기록된 상태

용어: 암흑질량 표현형

정의: 국소 뒤틀림 응력이 Reality의 추가 중력원으로 귀속된 상태; 보통물질 질량모드와 구별

* **용어:** 관계적 열림
  * **정의:** 구분 가능한 상태 경로와 양자화가 처음 성립한 빅뱅의 Actual 해석

용어: 우주 상태 전이

정의: 하나뿐인 Actual의 안정 조건이 무너질 때 다음 상태로 갱신되고 새 상태의 안정성에 따라 지속 또는 재갱신되는 과정

용어: 체험 시간

정의: 의식이 현재의 변화와 Record의 차이를 기억과 예측에 연결하여 흐름과 지속으로 구성한 시간 경험
