# 부록 B 주장의 출처와 등급

이 장부의 목적은 표준물리의 식을 WRRA의 새 도출로 오인하지 않도록 하면서, WRRA의 이론적 성과도 과도한 유보문 아래 묻히지 않게 하는 것이다.

**Ledger — 표지 · 뜻 · 사용 원칙**

* **표지:** **BASELINE**
  * **뜻:** 기존 물리학의 확립된 식·관측
  * **사용 원칙:** 출처와 적용범위를 명시
* **표지:** **DEFINITION**
  * **뜻:** WRRA가 새로 정한 층·소유권
  * **사용 원칙:** 정의에서 나오는 귀결과 구분
* **표지:** **THEORETICAL RESULT**
  * **뜻:** 가정에서 논리적으로 얻은 구조결론
  * **사용 원칙:** 가정과 반례범위를 함께 표시
* **표지:** **CONSTRUCTED/EXACT**
  * **뜻:** 지정 모형에서 정확히 구성·계산
  * **사용 원칙:** 전체 이론과 동일시하지 않음
* **표지:** **CALIBRATED**
  * **뜻:** 관측값으로 고정
  * **사용 원칙:** 독립도출로 부르지 않음
* **표지:** **PREDICTION**
  * **뜻:** 보정에 쓰지 않은 출력
  * **사용 원칙:** 절차·시점·실패조건을 동결
* **표지:** **OPEN**
  * **뜻:** 아직 미정인 연결
  * **사용 원칙:** 핵심 성과 뒤에 별도 목록으로 관리

## 물리모형 1.0 중력·질량 주장 등급 복원 장부

주장: compact S¹ 모드 분해와 질량 양자화

등급: CONSTRUCTED/EXACT

정확한 한계: 지정 witness 안에서 정확; 실제 모든 pole mass의 무입력 유도는 아님

주장: 질량–전하 이중 투영

등급: CLOSED IN UNIVERSAL WITNESS

정확한 한계: 단순 S¹의 고정 m/|q|는 실제 전체 스펙트럼에 불충분

주장: 중력–전자기 공통기하와 Lorentz force

등급: CLOSED IN UNIVERSAL WITNESS

정확한 한계: 고전적 기하 폐쇄; 완전한 양자중력·radion 미시기원은 별도

주장: d=3의 최소성

등급: CONDITIONAL THEORETICAL RESULT

정확한 한계: 국소 전파 massless spin-2와 비음수 비용 가정 아래의 최소

주장: 1세대 질량 저정수 격자

등급: CALIBRATED

정확한 한계: 전자질량으로 scale 고정; blind prediction 아님

주장: 중성미자 절대질량과 질량합

등급: DISCOVERY-CALIBRATED ⊕ FROZEN HOLDOUT

정확한 한계: Δm²를 발견 입력으로 사용; 절대질량·합만 동결 출력

주장: 중력 자체의 근본 양자화

등급: OPEN / NOT REQUIRED FOR CLASSICAL WITNESS

정확한 한계: 현재 모형은 중력을 n/R 규칙으로 양자화했다고 주장하지 않음

주장: 실제 표준모형 전체 질량·세대·Yukawa·혼합의 상류 매핑

등급: OPEN

정확한 한계: 앞의 일반 질량 기작과 닫힌 witness를 취소하지 않음
