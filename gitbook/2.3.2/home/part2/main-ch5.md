# 5장 네 힘은 왜 같은 힘이 될 수 없는가

중력과 세 게이지 힘의 통합은 네 항을 하나의 gauge field로 평탄화하는 일이 아니다. 서로 다른 소유권을 가진 네 표현이 하나의 현실 실행계에서 함께 작동함을 보이는 일이다.

전자기력·약력·강력은 물질이 가진 특정 표현전류를 선택해 읽는다. 중력은 특정 전하를 고르는 대신 구현된 모든 물리적 자유도의 응력에너지에 결합한다. 이 차이는 현상적 크기의 차이가 아니라 입력 장부의 종류가 다르다는 뜻이다.

Gμν + Λgμν = (8πG/c⁴) Tμν\_total, ∇μTμν\_total = 0 (5.1)

Dμ = ∇μ^geo − ig₁YBμ − ig₂TᵃWμᵃ − ig₃tᴬGμᴬ (5.2)

중력의 owner map을 O\_G(X)=Tμν\[X], 세 게이지 힘의 owner map을 O\_a(X)=J\_a\[X]라 하자. 완전한 Standard-Model singlet X가 Tμν\[X]≠0이면서 J₁\[X]=J₂\[X]=J₃\[X]=0일 수 있다. 그러면 중력은 X를 읽지만 세 게이지 힘은 읽지 못한다.

∃X : (J₁,J₂,J₃)\[X] = 0 ∧ Tμν\[X] ≠ 0 (5.3)

therefore O\_G ≠ f(O₁,O₂,O₃) for any current-only flattening f (5.4)

이 반례는 중력을 세 힘과 같은 선택적 gauge current로 완전히 환원하는 평면적 통합이 일반적으로 불가능함을 보인다. 중력은 구현 전체의 기하 장부를 읽고, 세 힘은 그 안의 내부 표현을 선택적으로 읽는다. 따라서 공통 기원은 가능하지만 동일 종류일 필요는 없다.

**Statement**

비대칭 통합 명제 중력 = 전체 구현의 공통 causal geometry. 전자기·약력·강력 = 같은 국소 상태의 선택적 내부 gauge 표현. 네 힘은 하나의 renderer에서 나오지만 서로 같은 장부를 읽지 않는다.

이 구조는 암흑물질의 위치도 자연스럽게 설명한다. gauge singlet이더라도 실제 에너지·운동량·압력을 가지면 중력에는 남는다. 반대로 추상적 정보량이나 계산복잡도만으로는 중력원이 되지 않는다. metric variation 아래 Tμν가 생길 때만 gravitational ledger에 들어간다.

그러므로 WRRA의 통합은 기존 대통일이론보다 “약한 실패”가 아니다. 목표가 다르다. 대통일은 gauge group과 결합상수의 공통 미시기원을 찾고, WRRA는 왜 중력과 gauge force가 동일한 현실 안에서 서로 다른 방식으로 보편성과 선택성을 동시에 가질 수 있는지를 설명한다. 두 과제는 경쟁할 수 있지만 동일한 채점표를 써서는 안 된다.
