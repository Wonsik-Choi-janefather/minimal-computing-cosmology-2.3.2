# 7장 물질은 숫자 목록이 아니라 표현형이다

질량·전하·스핀·위치를 따로 얻었다고 하나의 입자가 생긴 것은 아니다. 하나의 물리적 대상은 여러 속성이 같은 실행과 기록에 공동 귀속될 때 성립한다.

표준모형은 관측된 물질의 정밀한 phenotype grammar다. WRRA는 그 성공을 다시 이름 붙여 자기 성과로 주장하지 않는다. 대신 표준모형의 표현·결합·질량 생성이 우주 실행구조의 어느 층에서 소유되는지 묻는다.

m\_f(μ)=y\_f(μ)v(μ)/√2, det S\_f⁻¹(p)|p²=m²\_pole = 0 (7.1)

전하와 스핀은 표현속성이며, 질량은 단일 SOURCE 숫자가 아니다. 물리모형 1.0의 지정된 compact witness에서는 닫힌 내부 운동량 n/R이 mₙ²=m₀²+n²/R²의 이산 질량 전구체를 만든다. Reality에서 관측되는 pole mass는 이 상류 모드가 Higgs–Yukawa, self-energy, QCD 결합, RG 흐름과 stable pole·gap·threshold를 거쳐 귀속된 값이다. 따라서 ‘질량의 양자화된 일반 기작’과 ‘실제 모든 입자의 정밀 질량값 유도’를 구분한다. 전자는 지정 witness에서 닫혔고 후자의 완전한 매핑은 OPEN이다.

하나의 입자라는 말에는 공동귀속 조건이 숨어 있다. 질량·전하·스핀·위치가 같은 국소 관측대수, 같은 translation history, 같은 spectral pole과 같은 사건 기록에서 함께 읽혀야 한다. 서로 다른 계산에서 얻은 네 숫자를 표로 붙이는 것과 하나의 물리적 대상이 존재하는 것은 다르다.

Object X ⇔ co-owned{m, q, s, x} on (A\_local, history, pole, record) (7.2)

이 공동귀속 개념은 물질만이 아니라 복잡계 전체로 확장된다. 어떤 기능, 기억, 자원과 출력이 같은 대상의 것인지 정하지 않으면 설명은 상관관계의 목록에 머문다. WRRA의 ownership은 장식적인 용어가 아니라 “무엇이 무엇의 상태인가”를 고정하는 논리 장치다.

## 7.1 닫힌 내부 운동과 질량 양자화 — 물리모형 1.0 복원

닫힌 내부 원 S¹의 반지름을 R, 좌표를 y라 두면 주기 경계조건 때문에 허용 모드는 정수 n∈ℤ로 분해된다. 이 결과는 관측값을 맞춘 경험식이 아니라 지정된 compact witness의 경계조건에서 나오는 정확한 모드 분해다.

Φ(x,y)=Σₙ φₙ(x) exp(iny/R), pᵧ=n/R (7.3)

mₙ²=m₀²+n²/R², Eₙ²=|p⃗₃|²+mₙ² (7.4)

n=0 모드는 숨은 운동량이 없는 branch이고, n≠0 모드는 3차원 관측에서 timelike mass로 읽힌다. 그러므로 WRRA의 정확한 표현은 ‘질량은 양자화된 내부 모드에서 시작해 Renderer를 거쳐 질량 표현형으로 귀속된다’이다. ‘질량은 전적으로 후단의 이름일 뿐이다’라고 축약하면 1.0의 결과를 잃는다.

격자 점검: a=2πR/N일 때 m\_lat=2sin(π/N)/a이며 N=8…512 회귀에서 continuum 1/R에 대한 상대오차 지수는 약 −1.999845였다. 이는 예상된 O(N⁻²) 수렴을 수치적으로 재현한 검산이며, 새 입자질량의 독립 예측으로 세지 않는다.

주장 등급: CONSTRUCTED/EXACT — 지정된 S¹ witness 안의 모드 분해와 질량 양자화.

## 7.2 질량–전하 이중 투영 — 같은 n의 두 표현

동일한 내부 모드 정수 n은 질량과 전하로 서로 다르게 투영된다. 질량은 n의 부호에 짝이고, 전하는 부호를 보존한다.

n ↦ (mₙ,qₙ)=(√(m₀²+n²/R²), gn) (7.5)

m₀=0이면 n ↦ (|n|/R, gn); m₊ₙ=m₋ₙ, q₊ₙ=−q₋ₙ (7.6)

주장 등급: CLOSED IN UNIVERSAL WITNESS. 다만 가장 단순한 S¹은 고정된 m/|q|를 주므로 실제 표준모형의 모든 질량·전하 계층을 재현하지 못한다. 실제 스펙트럼에는 추가 내부구조, symmetry breaking과 dressing map이 필요하다. 따라서 ‘모든 pole mass가 하나의 보편 단위의 정수배’라는 주장은 하지 않는다.

## 7.3 중력–전자기 공통기하 — 물리모형 1.0 복원

compact fiber를 가진 metric witness에서 중력과 전자기력은 서로 다른 두 실체를 사후 결합한 것이 아니라 하나의 기하를 서로 다른 성분으로 읽은 결과다.

ds₅²=g\_{μν}dx^μdx^ν+R²(dθ+κA\_μdx^μ)² (7.7)

S₄=(1/16πG₄)∫d⁴x√−g \[R₄−(κ²R²/4)F\_{μν}F^{μν}] (7.8)

이 환원에서 Einstein 기하와 Maxwell 항이 같은 metric에서 나온다. 낮은 차원의 독립 곡률 검산은 R\_total=−κ²B²/2를 재현했고 최대 절대 결함은 6.07×10⁻¹¹이었다. 이는 계산 witness의 검증값이다.

p\_z=v\_z+κBxv\_y=constant, q=κp\_z (7.9)

a\_x=qBv\_y, a\_y=−qBv\_x (7.10)

숨은 운동량 보존은 4차원에서 Lorentz force로 읽힌다. 동시에 전자기장의 stress–energy도 같은 metric을 굽힌다. 이 범위에서 중력–전자기 공통기하와 질량–전하 이중 투영은 universal witness 안에서 CLOSED다. radion 안정화의 미시기원과 우리 우주의 전체 hierarchy는 별도 OPEN 항목이다.

차원 결과도 복원한다. D차원 질량 없는 spin-2의 국소 전파 자유도는 N\_grav(D)=D(D−3)/2이며, 공간차원 d로 쓰면 N\_grav(d)=(d+1)(d−2)/2다. C(d)=c\_Ed+c\_TN\_grav(d), c\_E,c\_T≥0이면 d≥3에서 C(d+1)−C(d)=c\_E+c\_Td>0이므로 arg min C(d)=3이다. 이는 ‘국소 전파 spin-2를 허용하는 차원들 가운데’의 조건부 최소성이지 모든 정보비용의 절대 최적성 증명은 아니다.

## 7.4 중력과 질량의 서로 다른 양자화 지위

현재 물리모형 1.0에서 양자화된 것은 닫힌 내부 운동의 모드 정수 n과 그 질량·전하 투영이다. 중력 자체에는 pθ=n/R과 같은 양자화 규칙을 부여하지 않았다. 중력은 phenotype 이전의 공통기하로서 구현된 전체의 T\_{μν}를 읽고, Reality에서는 일반상대론의 metric response로 계산된다.

질량: n∈ℤ → pθ=n/R → mₙ → mass phenotype (7.11)

중력: T\_{μν}^{total} → common geometry g\_{μν} → gravitational observables (7.12)

따라서 2.3.2의 판정은 ‘질량의 내부 모드는 양자화됨’, ‘중력 자체의 근본 양자화는 이 증명에 포함되지 않음’이다. 이것은 중력이 영원히 비양자적이라는 증명이 아니다. 완전한 양자중력은 선택적 미시 연구로 남지만, 그 미완성이 이미 닫힌 고전적 공통기하를 다시 OPEN으로 만들지는 않는다.
