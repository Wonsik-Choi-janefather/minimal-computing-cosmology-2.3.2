# 제6부 뒤틀림 응력 우주

제6부는 2.1의 미시 보강을 폐기하지 않고, 남아 있던 암흑부문을 WRRA의 Actual and Phenotype 구분으로 닫는다. 목표는 표준우주론보다 우월한 적합도를 선언하는 것이 아니라, 이미 관측된 은하와 우주가 하나의 최소 기하학적 응답으로 모순 없이 이해될 수 있는지를 확인하는 것이다.

**Ledger — 버전 · 주된 폐쇄 · 보존되는 것**

* **버전:** WRRA Core 1.0
  * **주된 폐쇄:** Domain agnostic 최소 실행 규칙
  * **보존되는 것:** 최소계산 공통운반자 표현형
* **버전:** MCC 2.0
  * **주된 폐쇄:** 우주 실행계와 공통운반자
  * **보존되는 것:** LAW SOURCE EXECUTION RENDERER REALITY RECORD
* **버전:** MCC 2.1
  * **주된 폐쇄:** 끈이론 미시재료를 이용한 보강
  * **보존되는 것:** MCC 뼈대와 세 불변축
* **버전:** MCC 2.2
  * **주된 폐쇄:** 뒤틀림 응력과 암흑물질 질량 표현형
  * **보존되는 것:** 2.1 전체와 WRRA Core 1.0
