# 14 실패 조건과 수정 순서

2.3.2는 모든 반론에 맞춰 Core를 바꾸지 않는다. 실패가 확인되면 가장 아래의 구현부터 수정한다. 관측 적합 모듈의 입력과 수치 구현을 먼저 확인하고, 다음으로 Renderer와 대응 정의를 검사한다. 그 뒤에 국소 또는 전역 뒤틀림 구현을 수정한다. WRRA Core는 실패가 Core 문법에서 직접 유도된 경우에만 별도 합의로 다시 연다.

* 하나의 전역 뒤틀림 대응으로 적색편이 거리 CMB와 구조 성장을 같은 FLRW 계량 안에서 재현할 수 없음이 증명될 때 전역 Renderer를 수정한다.
* 뒤틀림 응력 텐서가 보존 법칙 렌즈 동역학과 충돌 은하단의 비소산 거동을 함께 만족하지 못할 때 국소 응력 구현을 수정한다.
* 공통운반자 Renderer가 표준모형 게이지 대칭을 보존하면서 중복 자유도 없이 정의될 수 없을 때 해당 미시 구현을 폐기한다.
* 유한 무경계성과 비특권적 접합이 허용 가능한 우주 위상 및 관측 제한과 양립할 수 없을 때 위상 가설을 수정한다.
* 현재 상태의 갱신과 상대론적 공변성이 논리적으로 함께 성립할 수 없을 때 현재성의 물리 프로필을 다시 검토한다.

## 14 1 모듈 교체 규칙

새로운 검증 이론이 기존 모듈보다 넓은 범위에서 같은 현상을 더 정확히 계산하면 해당 Reality 모듈을 교체할 수 있다. 교체는 WRRA Core 변경을 뜻하지 않는다. 입력 출력 단위 보존 법칙과 관측 대응을 명시하고 이전 모듈과의 차이를 Record에 남긴다. 이 구조는 2.3.2가 미래 연구성과를 수용하면서도 이론의 기준을 잃지 않게 한다.
