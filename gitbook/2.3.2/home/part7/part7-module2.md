# 3 통합 규칙

## 3 1 모듈 채택

외부 이론은 네 조건을 동시에 만족하면 2.3.2의 공식 모듈이 된다. 첫째 관측 또는 실험으로 검증된 적용 범위가 있어야 한다. 둘째 WRRA의 고정 명제와 논리적으로 모순되지 않아야 한다. 셋째 어느 층의 무엇을 계산하는지 소유권이 명확해야 한다. 넷째 같은 물리량을 다른 모듈과 중복해 더하지 않아야 한다.

식 3 검증성 V 무모순성 C 소유권 O 비중복성 D로 정의한 모듈 채택 조건

모듈 채택은 그 이론의 모든 존재론을 함께 수입한다는 뜻이 아니다. 2.3.2는 계산 결과와 검증 범위를 채택하고, 존재론적 의미는 WRRA의 층위 규칙으로 다시 귀속한다. 출처 버전 적용 조건과 출력은 Record에 남긴다. 이 절차가 끝나면 결합은 완료되며 WRRA 내부 재유도는 의무가 아니다.

  * **모듈:** 최소계산우주론 2.3.2

  * **모듈:** 표준모형

* **지위:** 검증 계산
  * **모듈:** 일반상대론
  * **사용 범위:** 계량 중력 렌즈 궤도 중력파

## 3 3 통합이 허용하지 않는 것

* 공통운반자를 광자 글루온 W Z 옆에 놓는 추가 입자로 취급하지 않는다.
* Actual의 상태와 Reality의 입자 텐서를 동시에 중력원에 더하지 않는다.
* 끈이론의 추가 차원과 특정 진공을 2.3.2의 확정 명제로 자동 수입하지 않는다.
* 표준 우주론의 수치 성공을 버리지 않으며 임의의 보정항으로 다시 맞추지 않는다.
* 선택 연구의 미완성을 현재 관측을 설명하지 못한다는 뜻으로 바꾸지 않는다.
