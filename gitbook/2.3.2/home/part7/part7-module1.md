# 2 Actual Renderer Reality Record

2.3.2는 존재론과 계산을 한 문장에 섞지 않는다. Actual은 공통운반자 상태와 경계 관계 뒤틀림이 존재하는 층이다. Renderer는 Actual 상태를 입자 장 질량 거리 시간 같은 측정 가능한 표현형으로 귀속한다. Reality는 실험자가 사용하는 장방정식과 계량의 층이다. Record와 Ledger는 관측값 출처 적용 범위와 갱신 이력을 보존한다.

식 2 Actual에서 Reality와 관측량으로 가는 대응

그림 1 최소계산우주론의 네 층과 정보 흐름

층위 분리는 같은 대상을 두 번 더하는 오류를 막는다. 예를 들어 표준모형의 전자와 WRRA의 공통운반자 상태는 두 개의 전자가 아니다. 전자는 Reality에서 계산되는 표현형이고 공통운반자는 그 표현형이 발생하는 Actual의 기반이다. 암흑물질 텐서와 뒤틀림 응력도 같은 중력원을 두 언어로 기술하므로 동시에 더하지 않는다.

## 2 1 소유권 규칙

**Ledger — 대상 · Reality 계산 소유권 · Actual 해석 소유권**

* **대상:** 보통물질 입자와 세 힘
  * **Reality 계산 소유권:** 표준모형
  * **Actual 해석 소유권:** 공통운반자의 경계별 채널 표현형
* **대상:** 보통물질 질량
  * **Reality 계산 소유권:** 힉스 결합과 QCD 결합 에너지
  * Actual 해석 소유권: 닫힌 내부 모드 n/R의 이산 질량 전구체와 공동귀속 Renderer
* **대상:** 중력
  * **Reality 계산 소유권:** 일반상대론의 계량
  * Actual 해석 소유권: 전체 T\_{μν}를 읽는 공통기하와 metric response

대상: 중력의 양자화 지위

Reality 계산 소유권: 필요할 때 선택하는 양자중력 후보 모듈

Actual 해석 소유권: 현재 1.0 증명에서는 비양자화된 공통기하; 근본 양자화 여부는 별도 OPEN

* **대상:** 암흑물질 중력원
  * **Reality 계산 소유권:** ΛCDM의 CDM 유효 텐서
  * **Actual 해석 소유권:** 국소 뒤틀림 응력의 질량 표현형
* **대상:** 적색편이와 거리
  * **Reality 계산 소유권:** FLRW 척도인자와 광선 경로
  * **Actual 해석 소유권:** 전역 뒤틀림의 거리와 파장 표현형
* **대상:** 우주 가속
  * **Reality 계산 소유권:** Λ 또는 검증된 배경 모듈
  * **Actual 해석 소유권:** 전역 뒤틀림의 배경 표현형
